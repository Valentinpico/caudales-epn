# Base de Datos - INAMHI

Este directorio contiene los datos meteorológicos de precipitaciones y temperatura de INAMHI**. 

## Estructura y Descripción de los Archivos

* **DATA NACIONAL**  
  El archivo original del cual se extrajo toda la información meteorológica.
* **Base de datos cruda.xlsx**  
  Versión en formato Excel (`.xlsx`) de los datos extraídos para facilitar su visualización y filtrado rápido.
* **INAMHI_precipitacion_CRUDA.csv**  
  Archivo en formato CSV que contiene específicamente la base de datos de precipitaciones
* **INAMHI_temperatura_CRUDA.csv**  
  Archivo en formato CSV que contiene específicamente la base de datos de temperatura
